# Jobs To Be Done
## Host
When people want access to me, I want one link that understands what they need and still lets them book legitimate time, so I spend less effort triaging requests without making access frustrating.

## Visitor
When I need something from a person, I want the shortest path to the outcome — answer, context collection, or a meeting — without multiple forms and scheduling links.

## Functional jobs
Expose real availability without private event details; avoid double booking; create/cancel/reschedule; capture useful intent; select duration; degrade gracefully if AI fails; switch vendors without rewriting logic.

## Emotional constraint
The visitor must not feel a human has placed an annoying bot in front of them. AI must save visitor effort too.
