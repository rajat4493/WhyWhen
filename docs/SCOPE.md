# Scope
## V0 in scope
- solo host
- public slug page
- direct calendar booking
- intent textbox + AI classification
- 15/30/45/60 minute durations
- working hours, buffers, timezone
- Google Calendar adapter
- Microsoft/Outlook Calendar adapter
- Zoho Calendar adapter with verification gate
- cancel/reschedule domain flow
- AI Gateway + OpenAI-compatible + mock architecture
- Supabase persistence
- OAuth credential storage pattern
- MCP server/client architecture + minimal scheduling tools
- mobile-first minimalist UI
- Vercel + Docker-compatible hosting
- tests, ledger, handoff

## Architectural in V0, not necessarily fully surfaced UI
Gmail, Outlook Mail, Zoho Mail capability adapters; remote MCP connectors; provider webhooks.

## Out of scope
Teams/round-robin, payments, CRM, lead scoring suite, analytics cockpit, workflow builder, marketplace, collective availability, SMS/WhatsApp, native mobile, social profile, autonomous outbound email.
