# Minimal Design System
## Intent
Quiet, expensive utility. Restraint over “AI product” styling.

## Rules
Off-white page, white surfaces, near-black text, one restrained accent; no gradients/glow/glassmorphism/3D/confetti/AI sparkles; large typography + whitespace; one dominant CTA per state; borders before shadows; 120–180ms functional motion; mobile-first; WCAG AA; text/skeleton loading.

## Public page hierarchy
Host identity small → strong question → large intent box → Continue → immediately visible `Book a time`. No marketing clutter on a real person's page.

## Booking
Show duration + visitor timezone; compact date navigation; large slot tap targets; repeat exact date/time/timezone before confirm; never reveal busy event details.

## Dashboard
Only public link, availability policy, calendar, AI routing, integrations, bookings. Not an analytics cockpit.

## Copy
Short and human. Avoid “AI-powered”, “revolutionary”, “seamless”, and assistant chatter.
